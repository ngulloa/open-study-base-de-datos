Información incompleta y mundos posibles

Tablas de Codd, valuaciones, posibles mundos y consultas sobre bases de datos incompletas.

Intuición y concepto

Un NULL indica que la información disponible no determina completamente un dato. Una forma formal de entender esa incertidumbre es pensar que la tabla observada representa muchas bases de datos completas posibles. La Clase 06 introduce esta perspectiva mediante tablas de Codd y mundos posibles. (Riveros 2026)

El material hace una simplificación explícita: desarrolla la teoría para una base con una sola relación, señalando que el enfoque se extiende a esquemas con varias relaciones. Mantendremos esa misma presentación. (Riveros 2026)

Tablas de Codd

Sea Data el conjunto de datos, Att un conjunto infinito de atributos y Var un conjunto infinito de variables.

NotaDefinición del curso

Una tabla de Codd (T) es un subconjunto finito de tuplas con los mismos atributos, cuyos valores pertenecen a (DataVar), y donde cada variable aparece una sola vez. (Riveros 2026)

Ejemplo universitario:

rut nombre carrera
r1 Ana (x)
(y) Ben Computación
r3 Zoe (z)

Las variables (x,y,z) representan datos aún no determinados.

Variables de una tabla

El curso define

[ Var(T) = {(A)Var T, Aatt(T)}. ]

Una valuación es una función

[ :Var(T)DataData ]

tal que

[ (a)=a aData. ]

Es decir, la valuación elige un dato concreto para cada variable y deja intactas las constantes. (Riveros 2026)

Mundos posibles

NotaDefinición formal

Los posibles mundos representados por una tabla de Codd (T) son

[ Worlds(T) = {(T)T}. ]

(Riveros 2026)

T es una representación finita de un conjunto potencialmente muy grande —incluso infinito— de relaciones completas.

Esta idea es una base clásica para estudiar información incompleta. Foundations of Databases trata formalmente bases de datos incompletas y representaciones de posibles mundos; Database Theory incluye una parte dedicada a incertidumbre e información incompleta. (Abiteboul et al. 1995; Arenas et al. 2022)

Base de datos incompleta

La Clase 06 generaliza:

NotaDefinición del curso

Una base de datos incompleta (I) es un conjunto de relaciones ordinarias que comparten los mismos atributos:

[ R_1,R_2I, att(R_1)=att(R_2). ]

(Riveros 2026)

Ejemplos:

  • (Worlds(T)) para una tabla de Codd (T);
  • ({R}) para una relación completa (R);
  • ().

Consultas sobre información incompleta

Para una consulta (Q), el curso define:

[ Q(I)={Q(R)RI}. ]

Es decir, aplicamos la consulta a cada mundo posible. El resultado vuelve a ser una base de datos incompleta. (Riveros 2026)

Proyección

Si (I=Worlds(T)), entonces

[ {nombre}(I) = {{nombre}(R)RWorlds(T)}. ]

Cada mundo genera su propio resultado.

¿Toda consulta puede representarse otra vez con una tabla de Codd?

La Clase 06 formula la pregunta de cierre:

[ T’ Q(Worlds(T))=Worlds(T’)? ]

La respuesta es no. El curso entrega un contraejemplo con selección donde el conjunto de resultados posibles contiene tanto la relación vacía como una relación no vacía específica, y pide demostrar que ninguna tabla de Codd puede representar exactamente ese conjunto. (Riveros 2026)

Esto muestra una diferencia importante:

  • una representación puede ser finita y útil;
  • pero una clase de representaciones no tiene por qué ser cerrada bajo todas las consultas.

Relación con NULL

Una celda con NULL en SQL no es literalmente una variable de Codd. La teoría de mundos posibles se introduce para formalizar la intuición de información desconocida, no para afirmar que el estándar SQL implemente directamente Worlds(T). (Riveros 2026)

AdvertenciaNo confundir dos niveles
  • NULL y la lógica de tres valores describen la evaluación concreta de SQL.
  • Tablas de Codd, valuaciones y mundos posibles forman un modelo teórico de información incompleta.

Ambos temas están relacionados, pero no son la misma semántica operacional.

Qué queda fuera por ahora

La teoría de información incompleta incluye preguntas sobre respuestas ciertas, poder expresivo y representaciones más generales. El material disponible las señala como un área de investigación, pero no las desarrolla todavía. No las incorporaremos como páginas adicionales hasta contar con material suficiente del curso. (Riveros 2026; Arenas et al. 2022)

Resumen

  • Una tabla de Codd contiene constantes y variables que aparecen una sola vez.
  • Una valuación reemplaza variables por datos concretos.
  • Worlds(T) reúne todas las relaciones completas compatibles con la tabla.
  • Una consulta sobre una base incompleta se aplica a cada mundo posible.
  • Las tablas de Codd no son cerradas bajo todas las consultas.
  • Esta teoría formaliza información incompleta, pero no debe identificarse sin más con la ejecución de NULL en SQL.
