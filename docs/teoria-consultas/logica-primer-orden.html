Lógica de primer orden y consultas

Sintaxis y semántica de las consultas de primer orden sobre bases de datos relacionales.

Intuición y concepto

Una consulta debe depender de la forma de la base de datos y no de enumerar manualmente su contenido. La Clase 01 introduce la lógica de primer orden como primer lenguaje formal para declarar propiedades de los datos. (Riveros 2026)

Por ejemplo, sobre

Estudiante(rut, nombre, carrera)
Curso(codigo, nombre, creditos)
Inscribe(rut, codigo, semestre)

podemos expresar «estudiantes inscritos en IIC2413» diciendo que existe una tupla de Inscribe que conecta el RUT del estudiante con ese código.

Datos, variables y términos

El curso fija:

  • Data: conjunto de datos o constantes;
  • Var: conjunto de variables, con (DataVar=);
  • un término es un elemento de (DataVar). (Riveros 2026)

Usaremos (a,b,c,) para constantes y (x,y,z,) para variables.

Sintaxis

Sea (S=(N,ar)) un esquema posicional. Una fórmula () sobre (S) se construye recursivamente a partir de: (Riveros 2026)

[ \[\begin{aligned} \varphi ::= {} & x=a \mid x=y \mid R(t_1,\ldots,t_k) \\ &\mid \varphi_1\lor\varphi_2 \mid \varphi_1\land\varphi_2 \mid \neg\psi \\ &\mid \exists x.\psi \mid \forall x.\psi, \end{aligned}\]

]

donde (RN), (k=ar(R)) y cada (t_iDataVar).

Las tres primeras formas son atómicas; las restantes construyen fórmulas compuestas.

NotaComparaciones usadas en el curso

La Ayudantía 1 extiende las fórmulas atómicas con comparaciones

[ xa,xy, {<,>,,}, ]

con la semántica esperada. Esta extensión es útil para mantener una correspondencia directa con selecciones comparativas del álgebra relacional. (Saavedra 2026)

Variables libres y cuantificadas

Una variable es libre si su valor debe venir dado por una asignación externa; queda cuantificada cuando está bajo () o ().

Por ejemplo,

[ (x)=cs.; Inscribe(x,c,s)c= ]

tiene a (x) libre y a (c,s) cuantificadas.

El curso denota por (FV()) el conjunto de variables libres y por (Const()) las constantes mencionadas por la fórmula. (Riveros 2026)

Semántica

Sea (D) una base de datos del esquema. Una asignación () de () sobre (D) asigna a cada variable libre un elemento de

[ Dom(D)Const(). ]

El curso adopta además ((a)=a) para constantes (aData). (Riveros 2026)

La relación de satisfacción ((D,)) se define inductivamente. Los casos centrales son:

[ (D,)x=a (x)=a, ]

[ (D,)x=y (x)=(y), ]

[ (D,)R(t_1,,t_k) ((t_1),,(t_k))D(R). ]

Para los conectivos:

[ (D,) (D,) (D,), ]

con definiciones análogas para () y ().

Para los cuantificadores, el curso cuantifica sobre el dominio activo más las constantes de la fórmula:

[ (D,)x. (D,_{x/a}) aDom(D)Const(), ]

[ (D,)x. (D,_{x/a}) aDom(D)Const(). ]

Esta elección de semántica activa es importante cuando más adelante relacionemos lógica y álgebra relacional. (Riveros 2026; Arenas et al. 2022)

Consultas de primer orden

NotaDefinición del curso

Una consulta de primer orden tiene la forma

[ Q(x_1,,x_n), ]

con (FV(){x_1,,x_n}). Su respuesta sobre (D) es

[ Q(D)= {((x_1),,(x_n)) (D,)}. ]

(Riveros 2026)

AdvertenciaDetalle de la definición

Las diapositivas escriben la condición (FV(){x_1,,x_n}). La definición semántica usa valores para todas las variables de la cabeza. Para evitar el caso límite no desarrollado en el material, todos los ejemplos de este sitio harán que cada variable de la cabeza ocurra libremente en la fórmula.

Ejemplo: estudiantes inscritos en IIC2413

[ \[\begin{aligned} Q(n)\leftarrow\;&\exists r\exists c\exists s.\\ &Estudiante(r,n,c)\land Inscribe(r,\text{IIC2413},s). \end{aligned}\]

]

La consulta retorna los nombres de estudiantes para los cuales existe una inscripción compatible.

Ejemplo: cursos sin prerrequisitos

[ Q(n) ccr.; Curso(c,n,cr) p.;Requisito(c,p). ]

Aquí la negación de un existencial expresa «no existe ningún prerrequisito».

Universal como ausencia de contraejemplo

La equivalencia

[ x. x. ]

es especialmente útil para consultas de tipo «para todos». La Ayudantía 1 la destaca como patrón central de traducción entre lógica y álgebra. (Saavedra 2026)

La idea práctica es buscar un contraejemplo: una condición universal se cumple cuando no existe ningún elemento que la viole.

Resumen

  • Las relaciones de una base de datos se interpretan como predicados.
  • Una fórmula combina átomos mediante conectivos y cuantificadores.
  • La semántica del curso cuantifica sobre (Dom(D)Const()).
  • Una consulta (Q(x)) produce una relación con las asignaciones que satisfacen ().
  • «No existe» y «para todos» son patrones fundamentales para formular consultas.
