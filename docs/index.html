Modelo relacional, consultas, SQL y diseño

Este sitio presenta las bases conceptuales y prácticas de las bases de datos relacionales. Combina definiciones matemáticas, ejemplos y consultas SQL para estudiar cómo se representa la información, cómo se consulta y cómo se diseña un esquema.

Comenzar a estudiar Explorar los temas

El recorrido comprende el modelo relacional, la lógica y el álgebra de consultas, SQL, la información incompleta y el diseño mediante dependencias funcionales y descomposiciones. Las páginas se pueden leer en ese orden o consultar por concepto; cada una incluye ejemplos, un resumen y enlaces a los conocimientos relacionados.

Ejemplo transversal

La mayor parte del sitio utiliza un dominio universitario común:

Estudiante(rut, nombre, carrera)
Curso(codigo, nombre, creditos)
Profesor(pid, nombre, departamento)
Inscribe(rut, codigo, semestre)
Dicta(pid, codigo, semestre)
Requisito(codigo, prerrequisito)

Los datos son ficticios. Usaremos BD101 para Bases de Datos, PROG101 para Introducción a Programación y PROG201 para Programación Avanzada. Los identificadores r1, r2, etc., representan RUT simplificados; p1, p2, etc., identifican profesores ficticios. Cada ejemplo explicita las restricciones del dominio que necesita.

Convenciones editoriales

  • Las convenciones de notación se definen en el sitio: distinguimos aridades posicionales de conjuntos de atributos y explicitamos el dominio de evaluación de las consultas.
  • SQL se presenta como lenguaje real con semántica de duplicados y particularidades de motor, distinguiéndolo del modelo de conjuntos del álgebra relacional.
  • La bibliografía principal reúne obras de teoría y sistemas de bases de datos para fundamentar los conceptos y ampliar su estudio. (Arenas et al. 2022; Abiteboul et al. 1995; Garcia-Molina et al. 2009; Silberschatz et al. 2020; Ramakrishnan y Gehrke 2003)
  • Una definición se desarrolla en su página principal y, en el resto del sitio, se enlaza en vez de repetirse extensamente.
