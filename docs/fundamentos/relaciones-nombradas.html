Atributos y relaciones nombradas

Tuplas y relaciones con atributos explícitos, base formal para el álgebra relacional del curso.

Intuición y concepto

Una tupla posicional como

[ (r2,,) ]

solo puede interpretarse si sabemos qué significa cada posición. En la práctica, las relaciones tienen atributos: rut, nombre, carrera. La Clase 02 formaliza esta idea mediante tuplas y relaciones nombradas. (Riveros 2026a)

Los atributos permiten:

  1. referirse a una columna por nombre;
  2. modelar la estructura de los datos;
  3. presentar y combinar relaciones de forma más legible.

A partir de esta página, salvo que se indique lo contrario, la notación del sitio sigue las relaciones nombradas usadas por el curso.

Tuplas nombradas

Sea Data el conjunto de datos y Att un conjunto infinito de atributos.

NotaDefinición formal

Una tupla nombrada () es una función

[ :{A_1,,A_k}Data, ]

donde (A_1,,A_kAtt). (Riveros 2026a)

Su conjunto de atributos se denota

[ att()={A_1,,A_k}. ]

El curso utiliza la notación

[ =(A_1:a_1,,A_k:a_k) ]

para indicar que ((A_i)=a_i).

Por ejemplo:

[ =(rut:r2, nombre:, carrera:). ]

Como una tupla nombrada es una función cuyo dominio es un conjunto de atributos,

[ (A:a,B:b)=(B:b,A:a). ]

El orden de escritura ya no tiene significado semántico: el nombre del atributo queda unido al dato.

Tupla nombrada vacía

La tupla vacía es la única función

[ ():Data. ]

Conserva el mismo papel conceptual que la tupla vacía del modelo posicional. (Riveros 2026a)

Relaciones nombradas

NotaDefinición formal

Una relación nombrada (R) es un subconjunto finito de tuplas nombradas que tienen exactamente los mismos atributos:

[ R {att()={A_1,,A_k}}. ]

Definimos

[ att(R)={A_1,,A_k}. ]

(Riveros 2026a)

Para el dominio universitario:

rut nombre carrera
r1 Ana Ingeniería Civil
r2 Ben Computación
r3 Zoe Computación

representa la relación

[ \[\begin{aligned} Estudiante=\{& (rut:r1,nombre:\text{Ana},carrera:\text{IngenieríaCivil}),\\ & (rut:r2,nombre:\text{Ben},carrera:\text{Computación}),\\ & (rut:r3,nombre:\text{Zoe},carrera:\text{Computación})\}. \end{aligned}\]

]

con

[ att(Estudiante)={rut,nombre,carrera}. ]

De relaciones posicionales a nombradas

Toda relación posicional puede verse como una relación nombrada asignando atributos 1, 2, …, k a sus posiciones. Por ello, las relaciones nombradas generalizan la representación anterior. La Clase 02 adopta desde este punto la convención de llamar simplemente tupla y relación a las versiones nombradas cuando el contexto lo permite. (Riveros 2026a)

AdvertenciaConvención de notación del sitio

La Clase 01 usa (ar:NN) para la aridad. En la Clase 03, al introducir esquemas nombrados, se reutiliza el símbolo ar para asociar nombres de relaciones con conjuntos de atributos. (Riveros 2026b, 2026c)

Para evitar ambigüedad, este sitio mantendrá:

  • (ar(R)) para la aridad cuando se trabaje con el modelo posicional;
  • (att(R)) para los atributos de una relación nombrada;
  • cuando sea necesario hablar del esquema nombrado, se describirá explícitamente qué atributos corresponden a cada nombre, sin reutilizar ar con un segundo tipo.

Por qué los atributos son esenciales para el álgebra

Los operadores que veremos a continuación se definen sobre atributos:

  • selección, por ejemplo (_{carrera=}(Estudiante));
  • proyección, por ejemplo (_{nombre}(Estudiante));
  • renombramiento, por ejemplo (_{nombrenombreEst}(Estudiante));
  • join, que compara automáticamente atributos con el mismo nombre.

Esta es la razón por la que la álgebra relacional del curso se construye sobre relaciones nombradas.

Resumen

  • Una tupla nombrada es una función desde atributos hacia datos.
  • att(τ) y att(R) identifican los atributos de una tupla o relación.
  • El orden de escritura de los atributos no altera una tupla nombrada.
  • Las relaciones nombradas generalizan las relaciones posicionales.
  • En adelante, «tupla» y «relación» significarán normalmente sus versiones nombradas.
