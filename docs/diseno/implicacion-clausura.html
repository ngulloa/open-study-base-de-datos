Razonamiento con dependencias: implicación y clausura

Conjuntos de dependencias funcionales, implicación, equivalencia y algoritmo de clausura de atributos.

Intuición y concepto

Una base de datos rara vez tiene una sola dependencia funcional. Cuando conocemos un conjunto (F), algunas dependencias adicionales se siguen lógicamente de él. La Clase 08 formaliza este razonamiento y presenta la clausura de atributos como herramienta algorítmica. (Riveros 2026)

Satisfacción de un conjunto de dependencias

Sea (F) un conjunto de dependencias funcionales.

[ RF ]

significa que (R) satisface cada dependencia de (F):

[ RF (AB)F, ;RAB. ]

(Riveros 2026)

Implicación

NotaDefinición formal

Decimos que (F) implica (F’), escrito

[ FF’, ]

si para toda relación (R):

[ RF RF’. ]

(Riveros 2026; Arenas et al. 2022)

Para una sola dependencia escribimos, por ejemplo,

[ FAC. ]

Esto no pregunta si una instancia concreta satisface (AC), sino si toda relación que respete (F) necesariamente debe respetarla.

Equivalencia de conjuntos

(F) y (F’) son equivalentes cuando tienen exactamente los mismos modelos:

[ FF’ R, RF RF’. ]

(Riveros 2026)

Reglas trabajadas en clase

La Clase 08 introduce explícitamente dos reglas de razonamiento. (Riveros 2026)

Dividir y juntar

[ {AB_1B_m} {AB_1,,AB_m}. ]

Por ejemplo:

[ codigonombre creditos ]

es equivalente a

[ {codigonombre,;codigocreditos}. ]

Transitividad

[ {AB,;BC} AC. ]

Si un atributo determina otro, y ese segundo determina un tercero, el primero determina el tercero.

La bibliografía presenta sistemas axiomáticos completos para dependencias funcionales, pero el material del curso disponible hasta Clase 08 solo necesita estas reglas y el algoritmo de clausura. No adelantaremos una página separada de axiomas de Armstrong todavía. (Silberschatz et al. 2020; Garcia-Molina et al. 2009)

Dos problemas algorítmicos

La Clase 08 plantea: dado (F), (Riveros 2026)

  1. ¿es (A) una superllave?
  2. ¿se cumple (FAB)?

Ambos se resuelven calculando la clausura de (A).

Clausura de atributos

NotaDefinición formal

La clausura de (A) bajo (F) es

[ A^+ := {BFAB}. ]

(Riveros 2026)

Contiene exactamente los atributos individuales que están funcionalmente determinados por (A) según (F).

Ejemplo universitario

Supongamos una relación auxiliar

[ InscripcionDetallada(rut,nombreEst,carrera,codigo,nombreCurso,creditos) ]

con

[ F={ rutnombreEst carrera, codigonombreCurso creditos }. ]

Entonces:

[ {rut,codigo}^+ = {rut,codigo,nombreEst,carrera,nombreCurso,creditos}. ]

Por lo tanto, rut codigo determina todos los atributos de esta relación y es una superllave bajo (F).

En cambio:

[ {rut}^+ = {rut,nombreEst,carrera}, ]

por lo que rut no es superllave de InscripcionDetallada.

Algoritmo de clausura

La Clase 08 presenta el siguiente procedimiento: (Riveros 2026)

entrada: F y un conjunto de atributos A
clausura <- A
reglas   <- F

repetir
  si existe B -> C en reglas con B contenido en clausura:
    clausura <- clausura union C
    eliminar B -> C de reglas
hasta que no haya cambios

retornar clausura

La idea es simple: cada vez que ya conocemos todos los atributos del lado izquierdo de una dependencia, podemos agregar los del lado derecho.

Ejecución sobre el ejemplo

Inicio:

[ clausura={rut,codigo}. ]

Por rut → nombreEst carrera:

[ clausura= {rut,codigo,nombreEst,carrera}. ]

Por codigo → nombreCurso creditos:

[ clausura= {rut,codigo,nombreEst,carrera,nombreCurso,creditos}. ]

No quedan reglas aplicables que agreguen atributos nuevos; el algoritmo termina.

Corrección del algoritmo

La Clase 08 bosqueja una demostración en dos direcciones: (Riveros 2026)

  1. si un atributo entra a clausura, entonces realmente pertenece a (A^+);
  2. si un atributo no entra al finalizar, puede construirse una relación que satisface (F) pero viola (AB), por lo que (BA^+).

El primer punto se demuestra inductivamente sobre las iteraciones. El segundo usa dos tuplas que coinciden en los atributos de la clausura y difieren en los demás.

No expandiremos aquí los detalles que el propio material deja como ejercicio, pero mantendremos el resultado que la clase establece.

Resolver los dos problemas

NotaProposición de Clase 08

La clausura permite decidir:

[ A A^+=att(R), ]

[ FAB {B}A^+. ]

(Riveros 2026)

Esta es una de las herramientas algorítmicas más importantes del diseño relacional.

Resumen

  • (FF’) significa que toda relación que satisface (F) también satisface (F’).
  • Dos conjuntos son equivalentes si tienen exactamente las mismas consecuencias sobre todas las relaciones.
  • Dividir/juntar y transitividad permiten deducir dependencias.
  • (A^+) reúne todos los atributos determinados por (A).
  • Con la clausura podemos decidir implicación y superllaves.
