SQL y manipulación de datos

Conceptos Claves

DDL DML PRIMARY KEY FOREIGN KEY NOT NULL SQL

Introducción

SQL (Structured Query Language) es un lenguaje de programación declarativo para bases de datos relacionales. Su sintaxis y semántica se desarrollan en el estándar SQL, que define formalmente un conjunto de instrucciones para definir, manipular y consultar datos.

SQL está fuertemente basado en dos fundamentos teóricos:

  • Álgebra relacional: describe operaciones sobre relaciones (tablas), como selección, proyección, join, unión, diferencia.

  • Lógica de primer orden: permite expresar condiciones del tipo y propocisiones declarativas que cumplan o no ciertas condiciones.

El modelo relacional separa esquema y datos y en SQL esto se refleja con distintas familias de comandos:

  • DDL (Data Definition Language): define o modifica la estructura de la base de datos, como tablas y restricciones;
  • DML (Data Manipulation Language): modifica o consulta los datos almacenados en la base de datos, como insertar, actualizar o eliminar filas.

Comandos DDL (Data Definition Language)

CREATE TABLE

Crea una nueva tabla.

CREATE TABLE nombre_relacion (

  atributo1 tipo1,

  atributo2 tipo2,

  ...

);

Por ejemplo, para crear una tabla de estudiantes y otra de cursos:

CREATE TABLE Estudiante (

  rut     **VARCHAR**(12),

  nombre  **VARCHAR**(100),

  carrera **VARCHAR**(100),

  **PRIMARY KEY** (rut)

);

CREATE TABLE Curso (

  codigo   **VARCHAR**(20),

  nombre   **VARCHAR**(120),

  creditos **INTEGER**,

  **PRIMARY KEY** (codigo)

);

ALTER TABLE

Modifica la estructura de una tabla existente.

ALTER TABLE nombre_relacion
ADD COLUMN atributo tipo;

Por ejemplo, para agregar el atributo edad a la tabla de estudiantes:

ALTER TABLE Estudiante
ADD COLUMN edad **INTEGER**;

DROP TABLE

Elimina una tabla junto con todos los datos almacenados en ella.

DROP TABLE nombre_relacion;

Por ejemplo, para eliminar la tabla de estudiantes:

DROP TABLE Estudiante;

CREATE VIEW

Crea una vista a partir del resultado de una consulta.

CREATE VIEW nombre_vista AS

SELECT atributo1, atributo2, ...

FROM nombre_relacion

WHERE condicion;

Por ejemplo, para crear una vista con los estudiantes de Ingeniería:

CREATE VIEW EstudiantesIngenieria AS

SELECT rut, nombre

FROM Estudiante

WHERE carrera = 'Ingeniería';

DROP VIEW

Elimina una vista existente.

DROP VIEW nombre_vista;

Por ejemplo, para eliminar la vista de estudiantes de Ingeniería:

DROP VIEW EstudiantesIngenieria;

CREATE INDEX

Crea un índice sobre uno o más atributos de una tabla para acelerar ciertas búsquedas.

CREATE INDEX nombre_indice

ON nombre_relacion (atributo);

Por ejemplo, para crear un índice sobre el nombre de los estudiantes:

CREATE INDEX indice_nombre_estudiante

ON Estudiante (nombre);

DROP INDEX

Elimina un índice existente.

DROP INDEX nombre_indice;

Por ejemplo, para eliminar el índice sobre el nombre de los estudiantes:

DROP INDEX indice_nombre_estudiante;

TRUNCATE TABLE

Elimina todas las tuplas de una tabla, pero mantiene su estructura.

TRUNCATE TABLE nombre_relacion;

Por ejemplo, para eliminar todos los estudiantes sin eliminar la tabla:

TRUNCATE TABLE Estudiante;

Nota: TRUNCATE TABLE no está disponible en SQLite. En SQLite se utiliza:

DELETE FROM Estudiante;

La declaración de PRIMARY KEY corresponda a la llave.

Comandos DML (Data Manipulation Language)

INSERT INTO

Inserta una o más tuplas nuevas en una tabla.

INSERT INTO nombre_relacion (
  atributo1,
  atributo2,
  ...
)

VALUES (
  valor1,
  valor2,
  ...
);

Por ejemplo, para insertar un estudiante:

INSERT INTO Estudiante (
  rut,
  nombre,
  carrera
)

VALUES (
  '20.123.456-7',
  'Ana Pérez',
  'Ingeniería'
);

También se pueden insertar varias tuplas a la vez:

INSERT INTO Estudiante (
  rut,
  nombre,
  carrera
)

VALUES
  ('20.123.456-7', 'Ana Pérez', 'Ingeniería'),
  ('21.987.654-3', 'Juan Soto', 'Matemáticas');

UPDATE

Modifica los valores de una o más tuplas existentes.

UPDATE nombre_relacion

SET atributo1 = valor1,
    atributo2 = valor2

WHERE condicion;

Por ejemplo, para cambiar la carrera de un estudiante:

UPDATE Estudiante

SET carrera = 'Ciencia de Datos'

WHERE rut = '20.123.456-7';

Si se omite WHERE, se modifican todas las tuplas de la tabla:

UPDATE Estudiante

SET carrera = 'Ingeniería';

DELETE FROM

Elimina una o más tuplas de una tabla.

DELETE FROM nombre_relacion

WHERE condicion;

Por ejemplo, para eliminar un estudiante:

DELETE FROM Estudiante

WHERE rut = '20.123.456-7';

Si se omite WHERE, se eliminan todas las tuplas de la tabla:

DELETE FROM Estudiante;

MERGE

Permite insertar, actualizar o eliminar tuplas dependiendo de si existe una coincidencia entre dos conjuntos de datos.

MERGE INTO nombre_relacion AS destino

USING otra_relacion AS origen

ON condicion

WHEN MATCHED THEN
  UPDATE SET atributo = valor

WHEN NOT MATCHED THEN
  INSERT (atributo1, atributo2)
  VALUES (valor1, valor2);

Por ejemplo:

MERGE INTO Estudiante AS destino

USING NuevosEstudiantes AS origen

ON destino.rut = origen.rut

WHEN MATCHED THEN
  UPDATE SET nombre = origen.nombre

WHEN NOT MATCHED THEN
  INSERT (rut, nombre, carrera)
  VALUES (origen.rut, origen.nombre, origen.carrera);

Nota: MERGE forma parte del estándar SQL, pero SQLite no lo soporta directamente.

SELECT

Consulta datos almacenados sin modificar las tuplas.

SELECT atributo1, atributo2, ...

FROM nombre_relacion

WHERE condicion;

Por ejemplo, para obtener los estudiantes de Ingeniería:

SELECT rut, nombre

FROM Estudiante

WHERE carrera = 'Ingeniería';

Nota: SELECT muchas veces se clasifica separadamente como DQL (Data Query Language), ya que consulta datos pero no los modifica. En una clasificación amplia de SQL puede considerarse parte de las operaciones de manipulación de datos.

Tipos de datos

Los tipos SQL pueden agruparse en categorías como:

  • numéricos: INTEGER, SMALLINT, FLOAT, …;
  • caracteres: CHAR(n), VARCHAR(n), CLOB, …;
  • binarios: BLOB;
  • booleanos: BOOLEAN;
  • temporales: DATE, TIME, TIMESTAMP, …
AdvertenciaSQL estándar y motores reales

Los nombres, tamaños, conversiones y comportamiento exacto de los tipos dependen del RDBMS. Por ejemplo, distintos motores implementan de manera diferente números en punto flotante, booleanos y tipos de texto. Verifica los tipos soportados por el motor elegido.

Resumen

  • DDL define o modifica el esquema; DML modifica los datos.
  • CREATE TABLE agrega tipos y restricciones a la estructura relacional.
  • INSERT, UPDATE y DELETE alteran la instancia.
  • El soporte exacto de tipos y algunas operaciones de esquema depende del RDBMS.
  • NULL y las llaves tienen semántica propia, desarrollada en las páginas enlazadas.
